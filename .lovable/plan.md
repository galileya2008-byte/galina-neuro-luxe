
План: оба варианта — блок «Источники трафика» в нашей статистике + интеграция Яндекс.Метрики.

## Что делаем

### 1. Блок «Источники трафика» в админке (Статистика)
В `src/components/admin/AdminStats.tsx` добавлю новую карточку, которая группирует записи из `page_views` по домену поля `referrer` за последние 30 дней:
- Парсинг хоста из URL referrer.
- Категоризация: `Яндекс`, `Google`, `ВКонтакте`, `Telegram`, `Instagram`, `Facebook`, `WhatsApp`, `Прямые заходы` (пустой referrer), `Другое` (с указанием домена).
- Вывод списком с количеством переходов и долей в процентах.
- Сортировка по убыванию.

Никаких изменений в БД не нужно — данные уже собираются хуком `usePageTracking`.

### 2. Подключение Яндекс.Метрики
Чтобы счётчик работал на published-домене и не требовал правки кода при смене номера, сделаю так:

**a) Хранение номера счётчика**  
Добавлю в админку (вкладка «Статистика», сверху) маленькую форму «Яндекс.Метрика: номер счётчика» с сохранением в новую таблицу `site_settings` (key/value). Это удобнее, чем секрет — нужен на клиенте, а не в edge function, и легко поменять без редеплоя.

Миграция:
- Таблица `site_settings (key text PK, value text, updated_at timestamptz)`.
- RLS: всем `SELECT` разрешён (значения публичны, как и сам счётчик в HTML), `INSERT/UPDATE` — только админам через `has_role`.

**b) Загрузка счётчика на сайте**  
Создам компонент `src/components/YandexMetrika.tsx`:
- При монтировании читает `site_settings` по ключу `yandex_metrika_id`.
- Если значение есть — динамически вставляет официальный сниппет Метрики (`https://mc.yandex.ru/metrika/tag.js`) с `webvisor:true, clickmap:true, trackLinks:true, accurateTrackBounce:true`.
- Подключается в `src/App.tsx` рядом с `<PageTracker />`.
- Не загружается на маршрутах `/admin*`.

**c) Отслеживание SPA-переходов**  
Поскольку приложение SPA, добавлю в существующий `usePageTracking` вызов `window.ym(ID, 'hit', url)` при каждом изменении маршрута, чтобы Метрика считала переходы между страницами корректно.

### 3. Инструкция пользователю
В чате после реализации дам короткую пошаговую инструкцию:
1. Зайти на metrika.yandex.ru → создать счётчик для `galina-neuro-luxe.lovable.app`.
2. Включить Вебвизор и карту кликов.
3. Скопировать 8-значный номер.
4. Вставить в админке → Статистика → поле «Номер счётчика Яндекс.Метрики» → Сохранить.
5. Через 1–2 дня смотреть в кабинете Метрики: «Стандартные отчёты → Источники → Поисковые фразы».

## Технические детали
- Парсинг referrer: `new URL(referrer).hostname`, обёрнутый в try/catch (битые значения → «Другое»).
- Сопоставление доменов: regex по подстроке (`yandex`, `google`, `vk.com`, `t.me`/`telegram`, `instagram`, `facebook`/`fb.com`, `wa.me`/`whatsapp`).
- Снippet Метрики добавляется через `document.createElement('script')` чтобы не ломать SSR/гидрацию и грузиться только при наличии ID.
- `window.ym` типизируем как `any` через `declare global` в компоненте.
- Загрузка `site_settings` кэшируется на время сессии (одно чтение при маунте App).
